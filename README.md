# Beyond the black box: Physics-informed causal learning reveals mechanistic interactions in nanocrystalline alloy strengthening

This repository contains the code accompanying the paper:

**“Beyond the black box: Physics-informed causal learning reveals mechanistic interactions in nanocrystalline alloy strengthening”**

---

We present a **physics-informed causal learning framework** for identifying and quantifying fundamental strengthening mechanisms and their interactions in alloys. The framework integrates physical knowledges with structural causal modeling to enable both **causal discovery** and **causal intervention**.

The framework is demonstrated using a binary **Pt–Au alloy system**, revealing the **non-equivalent contributions of individual strenghening mechanisms** and identifies their **nonlinear interactions** in controlling alloy hardness.
